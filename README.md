Specialized in building **custom attribute macros** and **derive macros** using the `proc_macro` crate. I leverage `syn` for precise AST parsing and `quote` for code generation, enabling:

- Compile-time validation of architectural patterns
- Boilerplate reduction without runtime overhead
- Type-safe, declarative APIs

My focus lies in **systems-level development** — services where performance, reliability, and resource control are critical. TypeScript and React are used only when interfaces are necessary; they remain a complementary skill rather than a core specialization.
